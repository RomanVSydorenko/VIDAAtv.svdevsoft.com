💾 Method 1: USB Installation (Recommended)

The easiest way to install on your Hisense VIDAA TV

1 Enable Developer Mode

On your Hisense TV remote:

  • Press Home button
  • Navigate to Settings → System → About
  • Find Software Version and press OK 5 times quickly
  • Enter Developer Mode PIN: 0000 or 1234 (default)
  • ✅ Developer Mode is now enabled
2 Prepare USB Drive

On your computer:

  • Download tv-monitoring.wgt from the link above
  • Format a USB drive (FAT32 or exFAT recommended)
  • Copy tv-monitoring.wgt to the root directory of the USB drive
  • Safely eject the USB drive
3 Install on TV

On your Hisense VIDAA TV:

  • Insert the USB drive into your TV's USB port
  • Press Home → navigate to Apps
  • Look for Developer or My Apps section
  • Select Install from USB or Package Manager
  • Choose tv-monitoring.wgt from the list
  • Confirm installation
4 Launch the App
  • Press Home button
  • Go to Apps or My Apps
  • Find TV Monitoring app (or Komitex TV)
  • Press OK to launch
  • Enjoy watching! 🎉

🎉 Installation Complete!

Your Komitex TV app is now installed and ready to use. Use your remote control to navigate channels and programs.

🌐 Method 2: Network Installation (Advanced)

Install over your local network

⚠️ Requirements

This method requires Developer Mode enabled and your TV connected to the same network as your computer.

1 Enable Developer Mode

Follow the same steps as USB method to enable Developer Mode on your TV.

2 Get TV's IP Address

On your Hisense TV:

  • Go to Settings → Network → Network Status
  • Note your TV's IP address (e.g., 192.168.1.100)
3 Enable Network Installation

On your Hisense TV:

  • Go to Settings → System → Developer Settings
  • Enable USB Debugging or Network Installation
4 Install from Computer

Option A: Using HTTP Server

On your computer, open terminal/command prompt in the folder with tv-monitoring.wgt:

# Python 3
python3 -m http.server 8080

# Or Python 2
python -m SimpleHTTPServer 8080

On your TV's browser app, navigate to:

http://YOUR_COMPUTER_IP:8080/tv-monitoring.wgt

Option B: Using VIDAA SDK (if installed)

vidaa-cli install tv-monitoring.wgt --device 192.168.1.100

💡 Tip

Replace YOUR_COMPUTER_IP with your actual computer's IP address on the local network. You can find it using ipconfig (Windows) or ifconfig (Mac/Linux).

🏪 Method 3: VIDAA App Store (For Public Distribution)

Official distribution through VIDAA App Store

ℹ️ About This Method

This method is for app publishers who want to distribute their app publicly through the official VIDAA App Store. Users will be able to install it directly from the store on their TV.

1 Register as Developer
  • Visit VIDAA Developer Portal: developer.vidaa.com
  • Create a developer account
  • Complete registration and verification
2 Prepare App Package
  • Ensure your tv-monitoring.wgt meets VIDAA guidelines
  • Prepare app screenshots and descriptions
  • Create promotional materials (icons, banners)
3 Submit for Review
  • Upload tv-monitoring.wgt to developer portal
  • Fill in app information and metadata
  • Submit for VIDAA review
  • Wait for approval (typically 1-2 weeks)
4 App Goes Live
  • Once approved, app appears in VIDAA App Store
  • Users can install directly from their TV
  • No developer mode required for end users

⚠️ Important Notes

  • Apps must comply with VIDAA content and technical guidelines
  • Review process may take 1-2 weeks
  • For personal use, USB or Network installation is recommended

🔧 Troubleshooting

❌ App won't install

Solution: Make sure Developer Mode is enabled. Go to Settings → System → About → Press OK 5 times on Software Version.

⚫ Black screen after launch

Solution: Try reinstalling the app. Press Home, then relaunch. Check TV logs if available in Developer Settings.

🎮 Remote control not working

Solution: App may need focus. Press Home button, then launch the app again. Ensure the app is in the foreground.

📦 "Invalid package" error

Solution: Redownload tv-monitoring.wgt file. Ensure it's not corrupted. Check that your TV supports VIDAA platform.

🔌 USB not recognized

Solution: Try a different USB drive. Format it as FAT32. Make sure the .wgt file is in the root directory (not in a folder).

⚠️ "Unsigned app" warning

Solution: This is normal for development apps. You can safely proceed. For production distribution, get a VIDAA signing certificate.

⚠️ Important Information

  • This app is designed specifically for Hisense VIDAA smart TVs
  • Developer mode must remain enabled for unsigned apps
  • For Android TV installation, use the Android APK version instead
  • The .wgt package is not compatible with other TV platforms (Samsung Tizen, LG webOS, etc.)
